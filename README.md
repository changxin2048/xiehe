# 北京协和医学院4+4临床医学教育项目录取名单

这是一个简单的 Web 应用，用于展示北京协和医学院4+4临床医学教育项目历年录取学生名单。

## 功能

*   **按年级浏览**: 在左侧边栏点击不同的年级，可以查看该年级的录取学生名单和候补名单（如有）。
*   **搜索学生**: 在顶部的搜索框中输入学生姓名进行搜索，应用会显示包含该姓名的所有年级和学生列表。
*   **查看全部**: 点击侧边栏的“全部年级”可以查看所有年级的完整名单。

## 如何运行

1.  确保已安装 Node.js 和 npm。
2.  在项目根目录下运行 `npm install` 安装依赖。
3.  运行 `npm start` 启动应用。
4.  在浏览器中访问 `http://localhost:3000`。
